# My Timer — English Version

English version of the OJapp Free query-based timer.

```text
/timer-en/?time=5&mode=down&seconds=on&icon=blue
```

## Query parameters

| Parameter | Values | Description |
| --- | --- | --- |
| `time` | `1`–`60` | Timer duration in minutes |
| `mode` | `down`, `up` | Count direction |
| `seconds` | `on`, `off` | `on` shows total seconds; `off` uses min:sec |
| `icon` | `blue`, `red`, `green`, `purple` | Home screen icon |

After changing the settings, select **Use These Settings**. The timer reloads with the complete configuration stored in the URL. You can then add that URL to your home screen as a configured timer app.
